# 세션 데이터 정리

## 적용 범위

- 최초 세션 정리 구현 또는 보안 감사: 저장소 전체를 탐색합니다.
- 새 저장소·SDK·지속 작업 추가: 새 지점이 기존 정리 계약에 참여하는지만 확인합니다.
- 계정 간 데이터 누출 버그: 관련 저장 지점과 정리 순서를 다시 탐색합니다.

기능마다 저장소 전체를 반복해서 훑지 않습니다.

## 최초 탐색 대상

- DataStore·SharedPreferences의 사용자별 값
- 사용자 귀속 DB 행
- 파일·이미지 캐시·다운로드
- 싱글턴과 메모리 캐시
- 계정 수명의 DI 객체
- WorkManager 등 지속 작업
- 푸시 토큰의 사용자 매핑
- WebView·외부 로그인 세션
- 분석·크래시 도구의 사용자 식별자

확인하지 않은 항목을 없음으로 보고하지 않습니다.

## 정리 계약

- 각 저장소가 자기 정리 동작을 제공하고 중앙 세션 종료 흐름이 이를 조합합니다.
- 새 사용자 귀속 저장 지점이 계약에 참여하지 않으면 리뷰나 테스트에서 드러나게 합니다.
- 진행 중 작업과 새 쓰기를 먼저 차단한 뒤 데이터를 지웁니다.
- 각 정리는 여러 번 실행해도 안전하고 한 항목 실패가 나머지를 막지 않게 합니다.
- 서버 로그아웃 실패와 관계없이 로컬 세션은 종료할 수 있어야 합니다.
- 언어·테마처럼 기기 귀속 설정은 사용자 데이터와 구분해 보존합니다.
- 정리가 끝나기 전 인증 화면으로 복귀하지 않게 합니다.

토큰을 지우는 시점은 서버 로그아웃 호출과 경합하는 새 요청을 함께 고려해 정합니다.

## 결과와 검증

확인한 위치, 누락, 지울 항목, 보존할 항목, 실행 순서를 보고합니다. 실행은 `session-cleanup` 위험 태그로 `android-change-verification`에 넘깁니다. 전체 두 계정 회귀는 최초 구현·버그 수정·릴리스 보안 점검에서만 요구합니다.
