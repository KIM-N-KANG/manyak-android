# 알림과 외부 진입

## 전제

알림과 외부 링크는 지연·중복·유실·조작될 수 있는 입력입니다. 페이로드는 이동에 필요한 최소 식별자로 사용하고, 화면 데이터는 진입 후 권한을 확인해 다시 조회합니다.

## 알림

- 채널은 사용자가 독립적으로 끄고 싶어 할 단위로 나눕니다.
- 런타임 알림 권한은 알림의 가치를 이해할 수 있는 시점에 요청합니다.
- 등록 토큰의 발급·갱신·서버 등록 실패·로그아웃 해제 경로를 둡니다.
- 중복 제거, 순서 판정, 유효성 확인이 필요하면 서버 페이로드에 식별자와 발생 시각 또는 버전이 있어야 합니다.
- 시스템 표시와 앱 직접 표시 중 필요한 제어가 가능한 방식을 서버와 합의합니다.
- 잠금화면에 민감한 내용을 노출하지 않습니다.

## 외부 진입

- 알림, 검증된 도메인 링크, 공유 인텐트를 하나의 해석 경계에서 내부 라우트로 바꿉니다.
- 외부 파라미터를 검증하고 없거나 접근할 수 없는 대상의 안전한 도착 화면을 정합니다.
- 인증이 필요하면 로그인 뒤 원래 목적지로 이어지는 정보를 보존합니다.
- 프로세스가 없는 상태와 실행 중 상태 모두 같은 화면 상태로 수렴하게 합니다.
- 상세 진입 뒤의 부모 백스택과 같은 화면 중복 진입 규칙을 정합니다.
- 이미 배포된 링크 형식을 바꿀 때는 구버전 호환 기간을 서버와 합의합니다.

## 결과와 검증

채널·토큰·페이로드·라우트 결정과 서버 합의 항목만 남깁니다. 프로젝트 공통 계약이 바뀔 때만 `docs/plans/_project.md`를 갱신합니다.

실제 확인은 변경 내용에 따라 `push-registration`, `notification-delivery`, `external-entry`, `permission` 중 필요한 위험 태그만 `android-change-verification`에 넘깁니다. 기능 완료 시에는 변경된 경로만 확인하고, 전체 알림 상태·기기 매트릭스는 릴리스 또는 명시적 QA 요청에서만 수행합니다.
