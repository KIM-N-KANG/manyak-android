# 이프 수치 서버 정책 연동

- 작성일: 2026-09-01
- 지라: KNK-1096 (상위 KNK-1089 · 웹 선행 KNK-1095)
- 근거 정본: 하네스 `3-1-client.md §3-1-7 이프 정책 수치 표시`, `3-3-android-app.md §3-3-4 이프 정책 수치 패칭`

## 목표와 제외 범위

화면에 박혀 있던 이프 수치를 지우고 `GET /credits/policies` 가 내려주는 값을 렌더한다. 운영이 정책을
바꿀 때 스토어 배포 없이 화면이 따라가게 하는 것이 목적이다.

**이번 범위** — 정책 조회 배선(도메인·데이터·DI), 수치를 쓰는 화면 여섯 자리 교체, 값이 오기 전·조회
실패 시의 자리표시 표시.

**제외** — 소모 지점 고지의 나머지(스토리라인 남은 횟수·재생성 버튼 주변)는 웹도 미구현이라 공통 잔여로
남긴다. 가입 보상(`signupReward`)은 앱이 문구로 노출하지 않아 쓰지 않는다.

## 새로 내린 결정

1. **조회 결과는 앱 수명 동안 한 곳에 둔다.** `CreditPolicyRepositoryImpl` 이 `@Singleton` 으로
   `StateFlow<CreditPolicy?>` 를 들고, `RootViewModel` 이 `init` 에서 한 번 `refresh()` 한다. 수치를
   쓰는 화면이 `:feature:create`·`:feature:chat`·`:feature:my` 세 모듈에 걸쳐 있어 화면마다 부르면 같은
   값을 여러 번 읽는다. 하네스가 `결정 필요`로 남겨 둔 자리다.
2. **화면에는 `CompositionLocal` 로 내린다**(`LocalCreditPolicy`). 여섯 자리가 다섯 개 화면에 흩어져
   있어 ViewModel 마다 상태·이벤트를 늘리면 MVI 배선만 다섯 벌이 된다. 화면의 관심사는 "지금 값이
   무엇인가" 하나뿐이고 화면이 조회를 시작하지도 않으므로 상태 기계에 넣을 것이 없다. 테마 토큰이 이미
   같은 방식으로 내려간다.
3. **대체 수치를 두지 않는다.** 값이 없으면 `creditAmountText()` 가 자리표시 숫자 `000` 을 돌려주고
   쓰는 쪽이 맥박(`creditAmountAlpha`)을 얹는다. 앱이 든 값은 서버가 정책을 바꾸는 순간 거짓이 되고,
   스토어 배포 주기가 길어 고치는 데도 오래 걸린다. 문구 골격은 그대로 남아 값이 도착해도 줄 높이가
   바뀌지 않는다.
4. **맥박은 `rememberSkeletonPulseAlpha()` 를 그대로 쓴다.** 골격을 깔아 두고 값을 기다리는 자리라
   조회 중 목록과 같은 성격이다. 새 애니메이션을 만들면 같은 뜻의 움직임이 두 벌이 된다.
5. **조회 실패를 화면에 알리지 않는다.** 실패해도 들고 있던 값을 지우지 않고, 못 받은 자리는 자리표시로
   남는다. 수치는 화면의 주된 정보가 아니라 보조 안내라 오류 안내를 띄울 자리가 아니다.
6. **토스트·공유 문구는 그 순간의 값을 읽는다.** 쉬머를 얹을 대상이 없는 자리다. 초대 등록 성공 토스트는
   `rememberUpdatedState` 로 최신 문구를 들고 있다가 사건이 났을 때 읽고, 공유 문구는 조합 때마다 다시
   만들어진다. 둘 다 화면을 띄운 뒤 동작하는 흐름이라 보통은 이미 도착해 있다.
7. **천 단위 구분자는 기기 로케일이 아니라 `Locale.KOREA` 로 고정한다.** 문구가 한국어 하나뿐이라
   기기 설정에 따라 숫자만 다른 규칙으로 끊기면 같은 문장 안에서 어긋난다. 턴 수 표시가 기본 로케일을
   쓰는 것과 갈리는데, 그쪽은 문장에 섞이지 않는 단독 숫자다.
8. **`MyMenuItem` 의 보조 문구는 리소스 ID 가 아니라 완성된 문자열을 받는다.** 수치를 실어야 해서
   `@StringRes subLabelRes` 로는 만들 수 없다. 확정 전 값이면 `subLabelPending` 으로 알려 맥박을 준다.

## 구현 순서

1. `:core:domain` — `CreditPolicy`(여섯 필드, 전부 nullable)·`CreditPolicyRepository`
2. `:core:data` — `CreditPolicyResponseDto`·`CreditPolicyApi`(`@PlainClient` — 인증 불필요)·
   `CreditPolicyRepositoryImpl`·DI(`NetworkModule`·`SettingsModule`)
3. `:core:ui` — `LocalCreditPolicy`·`creditAmountText()`·`creditAmountAlpha()`
4. `:app` — `RootViewModel` 이 정책을 노출하고 `ManyakApp` 이 조합에 내림
5. `:core:ui` 문자열 — 수치를 `%1$s` 인자로 뺌(9개)
6. 화면 여섯 자리 — 완성 비용·턴 비용·출석 제목·초대 메뉴 보조 문구·초대 화면 안내·초대 안내 시트 제목,
   그리고 문자열을 함께 쓰는 등록 성공 토스트·공유 문구

## 남은 것

- 실패한 조회를 다시 읽을 계기가 앱 재실행뿐이다. 정책이 바뀌는 빈도가 낮고 자리표시가 화면을 막지
  않아 이번 범위에서는 재시도를 두지 않았다. 사용자가 자리표시를 오래 보는 사례가 확인되면 화면 복귀
  갱신에 얹는다.
