# 홈 공개 스토리 목록 필터·정렬·무한 스크롤

- 작성일: 2026-09-26
- 지라: KNK-1429 (상위 KNK-1428 · 웹 KNK-1421·KNK-1426)
- 근거 정본: 하네스 `spec/3-1-client-spec.md` FE-SCREEN-001, `spec/3-3-android-spec.md §3-3-2 스토리 목록·상세`, `design/1-2-android-design.md §1-2-4`

## 범위

홈 조회를 폐기 예정 `GET /stories/originals`에서 `GET /stories`(`filter`·`sort`·`cursor`)로 옮기고, 전체·오리지널 필터 칩과 인기순·최신순·채팅순 정렬, 커서 무한 스크롤, 스크롤 방향에 따른 필터·정렬 바 숨김을 넣는다. ORIGINAL 태그는 응답의 `isOriginal`로만 그린다. 지표 축약·좋아요 노출은 KNK-1430 범위다.

## 결정

1. **선택은 `HomeViewModel` 수명 동안만 유지한다.** 탭 전환·구성 변경은 넘기고 프로세스 종료 뒤에는 전체·인기순으로 연다. 복원해도 첫 페이지부터 다시 읽어야 해 저장할 이유가 약하다.
2. **요청 조건은 ViewModel 안의 값을 바로 바꿔 쓴다.** 상태의 `query`는 reduce를 거쳐 늦게 바뀌므로, 칩과 정렬을 연달아 바꿀 때 이전 조건으로 요청하지 않게 한다.
3. **첫 페이지와 다음 페이지를 한 작업으로 직렬화한다.** 조건을 바꾸거나 당겨서 새로고침하면 진행 중인 다음 페이지를 취소해 이전 조건의 페이지가 섞이지 않는다. 페이지 사이 중복은 `distinctBy(id)`로 먼저 받은 자리를 남긴다(그리드 키 중복 크래시도 막는다).
4. **바는 그리드 위 오버레이로 두고 그리드가 바 높이만큼 위 여백을 비운다.** 바가 자리를 차지하면 숨고 나타날 때 목록이 움직인다. 숨김은 그리드가 실제로 소비한 스크롤만 세어 끝에서의 당김은 무시한다.
5. **목록 끝 재시도와 정렬 메뉴는 기존 컴포넌트를 올려 쓴다.** 이프 내역의 푸터를 `designsystem/LoadMoreFooter`로, 셀렉트의 메뉴를 `ManyakSelectMenu`로 공개했다(두 번째 사용처).
